# Support

Email **digital-templates@zohomail.in** (Template Craft). I answer within 3 working days. GitHub Issues are disabled so support stays in one place.

## What to send

- operating system and version
- Python version (`py -3 --version` or `python3 --version`)
- the exact command you ran
- the full error text
- a terminal screenshot with keys redacted

## What not to send

- `RAZORPAY_KEY_SECRET`
- `RAZORPAY_WEBHOOK_SECRET`
- `ADMIN_TOKEN`
- `.env`
- customer payment data

## What is covered

Setup errors, installer failures, dependency problems, and questions about the documented install flow.

Not covered: custom development, tax advice, GST filing, Razorpay account approval, or running your server.
