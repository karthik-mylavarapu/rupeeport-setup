# RupeePort buyer guide — one-time installation

This guide takes you from the downloaded zip to a working **Test Mode** checkout on your own computer.

RupeePort is a FastAPI app that you run. It is not a hosted service. You do **not** need to be a programmer, but you should be comfortable copying commands into a terminal. If you get stuck, send the exact error text — never send your Razorpay keys or your `.env` file.

---

## 1. Before you start

| You need | Why | Needed for local test? |
|---|---|---|
| Windows 10/11, macOS 12+, or a modern Linux | The kit runs on all three | Yes |
| **Python 3.10 or newer** (3.12 recommended) | Runs the app and the installer | Yes |
| Internet access | The installer downloads Python packages | Yes |
| A **Razorpay account** in Test Mode | Creates the test checkout | Only for checkout |
| **Razorpay Key ID** and **Key Secret** | The app talks to your Razorpay account | Only for checkout |
| A **webhook secret** | Verifies Razorpay webhooks | Yes, for webhooks |
| Business name, address and email | Printed on checkout pages and invoices | Yes |
| GST state code | Decides CGST/SGST vs IGST | Yes |
| GSTIN | Prints a tax invoice; leave blank for Bill of Supply | Optional |
| A domain with HTTPS | Live webhooks and real payments | Only for live |
| A text editor | Edit `.env` and `app/products.py` | Yes |
| Product names, prices and SAC codes | Your store catalogue | Yes |
| A server or Docker host | Keeps the app online | Only for live |

**You can run the 45 automated tests with no Razorpay account and no keys.** The checkout only works after you add Test Mode keys.

## 2. Collect these values first

Write them down before running the installer. Do not paste them into a public chat, issue tracker or screenshot.

| Value | Where to get it | Example |
|---|---|---|
| Razorpay Key ID | Razorpay Dashboard → **Test Mode** → Account & Settings → **API Keys** → Generate Test Key | `rzp_test_xxxxxxxxxxxx` |
| Razorpay Key Secret | Same screen. It is shown once; copy it then | `aBcD...` |
| Business name | Your legal or trading name | `Acme Digital Services` |
| Business address | The address printed on invoices | `Plot 12, Hitech City, Hyderabad, Telangana 500081` |
| Business email | Billing/support email | `billing@example.com` |
| GST state code | Your place of business | `36` = Telangana, `29` = Karnataka, `27` = Maharashtra |
| GSTIN | Your 15-character GSTIN, or blank | `36ABCDE1234F1Z5` |
| Public base URL | `http://localhost:8000` for local; your HTTPS domain for live | `https://pay.example.com` |
| Webhook secret | Create any long random string, or let the installer generate one | Generated by installer |
| Admin token | The installer generates it; you do not need to provide one | Generated by installer |

### Razorpay keys: exact steps

1. Sign in to the [Razorpay Dashboard](https://dashboard.razorpay.com/).
2. Switch to **Test Mode** (toggle at the top).
3. Go to **Account & Settings → API Keys**.
4. Click **Generate Test Key**.
5. Copy the **Key ID** and **Key Secret**.
6. Keep Test Mode on until the full test payment and webhook pass.

For live payments later: complete Razorpay KYC, switch to **Live Mode**, generate **live** keys, and create a **separate live webhook**. Test and live webhooks are not shared.

## 3. Install Python 3.10+

The installer checks this for you, but install it first.

### Windows

1. Download Python from [python.org/downloads](https://www.python.org/downloads/).
2. Run the installer.
3. Tick **Add python.exe to PATH** before clicking Install.
4. Open **Command Prompt** or **PowerShell** and check:

```powershell
py -3 --version
```

Expected: `Python 3.10` or newer. If `py` is missing, try `python --version`.

### macOS

Open **Terminal** and check:

```bash
python3 --version
```

If it is missing or older than 3.10, install the latest Python from [python.org/downloads](https://www.python.org/downloads/). Homebrew (`brew install python`) also works if you already use Homebrew.

### Linux (Ubuntu/Debian)

```bash
python3 --version
sudo apt update
sudo apt install -y python3 python3-venv python3-pip
```

Expected: `Python 3.10` or newer.

## 4. Unzip the kit and open a terminal

### Windows

1. Right-click the downloaded zip → **Extract All**.
2. Open the extracted `rzp-kit` folder.
3. Right-click inside the folder → **Open in Terminal** (or **Open PowerShell here**).
4. Run `dir` and confirm you can see `app`, `requirements.txt`, `.env.example` and `README.md`.

### macOS

1. Double-click the zip to extract it.
2. Open **Terminal**.
3. Go to the folder, for example:

```bash
cd ~/Downloads/rzp-kit
```

4. Run `ls` and confirm you can see `app`, `requirements.txt`, `.env.example` and `README.md`.

### Linux

```bash
unzip Razorpay_UPI_Starter_Kit_v*.zip
cd rzp-kit
ls
```

If the folder name is different, use the actual name.

## 5. Run the installer

The installer is the file `rupeeport_setup.py`.

### If the file is already inside the kit as `scripts/setup.py`

**Windows:**

```powershell
py -3 scripts\setup.py
```

**macOS / Linux:**

```bash
python3 scripts/setup.py
```

### If you downloaded the installer separately

**Windows:**

```powershell
py -3 rupeeport_setup.py --project-dir C:\path\to\rzp-kit
```

**macOS / Linux:**

```bash
python3 rupeeport_setup.py --project-dir /path/to/rzp-kit
```

Replace the path with the folder that contains `app/main.py`. If you are already inside the kit folder, you can usually omit `--project-dir`.

### What the installer does

1. Checks Python 3.10+.
2. Creates a local `.venv` folder.
3. Installs the Python dependencies.
4. Creates `.env` from `.env.example`.
5. Generates an admin token and a webhook secret.
6. Runs the 45 automated tests.
7. Prints the exact start command and admin URL.

It does **not** create a Razorpay account, register a webhook, configure a domain, deploy the app or file GST.

## 6. Answer the prompts

The installer asks for the values you collected. Press **Enter** to keep the value in brackets.

| Prompt | What to enter |
|---|---|
| Business name | Your legal/trading name |
| Business address | Address printed on invoices |
| Business email | Billing/support email |
| GST state code | Two digits, e.g. `36` |
| GSTIN | 15 characters, or press Enter if not registered |
| Public base URL | `http://localhost:8000` for local; your HTTPS domain for live |
| Razorpay Key ID | `rzp_test_...` for the first install |
| Razorpay Key Secret | Paste it; the terminal hides it |
| Razorpay Webhook Secret | Paste one you already created, or press Enter to generate one |

The installer **generates** the admin token itself. You do not need to invent or paste one. It is saved in `.env`.

Notes:

- The Key Secret and Webhook Secret are hidden while pasting. That is normal.
- If you skip the Razorpay keys, the tests still run, but checkout will not work until you add them.
- If you paste a live key, the installer warns you. Go back to Test Mode.
- The installer writes `.env`. Never commit it, email it or send it in a screenshot.
- If `.env` already exists, the installer keeps it. Use `--reconfigure` to update it and back up the old one.

## 8. Start the app

**Windows:**

```powershell
.venv\Scripts\python -m uvicorn app.main:app --reload
```

**macOS / Linux:**

```bash
.venv/bin/python -m uvicorn app.main:app --reload
```

Open:

- Store: `http://localhost:8000`
- Admin: the URL printed by the installer, or `http://localhost:8000/admin?token=YOUR_ADMIN_TOKEN`

Keep the terminal open while you use the app. Press **Ctrl+C** to stop it.

If port 8000 is busy, use another port:

```bash
.venv/bin/python -m uvicorn app.main:app --reload --port 8001
```

Then set `BASE_URL=http://localhost:8001` in `.env`.

## 9. Make a test payment

1. Open the store.
2. Choose a product.
3. Click **Continue to payment**.
4. In Razorpay Test Mode, use UPI ID `success@razorpay` for a successful payment.
5. Use `failure@razorpay` to test a failed payment.
6. After success, open the receipt and download the invoice PDF.

Test Mode does not move real money.

## 10. Configure the webhook

Webhooks are the source of truth. The browser can close after payment; the webhook is what marks the order paid.

### On your laptop

Razorpay cannot reach `localhost`. Use the included simulator:

```bash
# Find the order_... id in /admin or data/app.db first
python scripts/simulate_webhook.py payment.captured --order order_ABC123 --amount 235882
```

The simulator signs the payload the same way Razorpay does.

### On a public HTTPS domain

1. Deploy the app with HTTPS first. See section 12.
2. In Razorpay: **Dashboard → Webhooks → Add new webhook**.
3. URL: `https://YOUR-DOMAIN/webhooks/razorpay`
4. Secret: the value of `RAZORPAY_WEBHOOK_SECRET` in `.env`.
5. Select the 13 events listed in the kit README:
   `payment.captured`, `payment.failed`, `order.paid`, `payment_link.paid`,
   `refund.processed`, `refund.failed`, `subscription.authenticated`,
   `subscription.activated`, `subscription.charged`, `subscription.pending`,
   `subscription.halted`, `subscription.cancelled`, `subscription.completed`.
6. Send a test event and confirm it appears in the admin.

If the webhook returns `401`, the secret in Razorpay and `.env` do not match.

## 11. Make the store yours

### Products and prices

Edit `app/products.py`:

```python
PRODUCTS = {
    "consult-60": {
        "name": "1-hour consultation call",
        "base_rupees": 1999,
        "sac": "998311",
        "blurb": "Video call, recording and notes included.",
    },
}
```

Prices are **GST-exclusive**; the app adds GST. The browser never sends the price; the server decides it.

Ask your CA for the correct SAC/HSN code for each item.

### Business and GST

Edit `.env` for business details, GSTIN, `BASE_URL`, invoice prefix and GST rate. Restart the app after changing `.env`.

Do not edit the payment verification or webhook logic unless you know what you are doing.

## 12. Go live

1. Complete **Razorpay KYC/activation**.
2. Switch to **Live Mode** and generate **live keys**.
3. Create a **separate live webhook** with the live secret.
4. Set a real `ADMIN_TOKEN` (the app refuses the placeholder with live keys).
5. Set `BASE_URL=https://your-domain` and your GSTIN.
6. Deploy with Docker on Railway, Render, Fly.io or a VPS.
7. Use a **persistent volume** for `data/` or a Postgres `DATABASE_URL`.
8. Take one real **₹1** payment, download the invoice, then refund it.
9. Back up the database and `.env`.
10. Keep Test Mode for future tests; never mix test and live keys.

```bash
docker compose up -d --build
```

## 13. Troubleshooting

| Problem | What to check |
|---|---|
| `python` is not recognized | Windows: use `py -3`. macOS/Linux: use `python3`. Install Python 3.10+ |
| `Python 3.9` or older | Install a newer Python; the kit needs 3.10+ |
| `venv` or `ensurepip` error | Linux: `sudo apt install python3-venv python3-pip` |
| `pip` cannot download | Check internet/proxy; retry; corporate networks may block PyPI |
| Tests fail | Send the full output. Do not edit tests to make them pass |
| Razorpay key error | Confirm you copied the full Key ID and Secret; use Test Mode keys; regenerate if needed |
| Webhook returns 401 | `RAZORPAY_WEBHOOK_SECRET` and the Razorpay webhook secret must match exactly |
| Webhook never arrives | Use a public HTTPS URL, not localhost; check the event list and live/test mode |
| GSTIN rejected | Use a valid 15-character GSTIN, or leave it blank for Bill of Supply |
| Port 8000 busy | Add `--port 8001` and set `BASE_URL` to match |
| `.env` already exists | The installer keeps it. Run with `--reconfigure` to update and back it up |
| Windows SmartScreen warning | Only relevant to a packaged `.exe`; verify the SHA-256 from the official release before running |

## 14. Security rules

- Never share `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET` or `ADMIN_TOKEN`.
- Never commit `.env` to GitHub.
- Use Test Mode keys until the full test passes.
- If a key leaks, rotate it in Razorpay immediately.
- Use HTTPS for live payments and webhooks.
- Back up `data/` and `.env`; losing them loses orders and invoice numbering.
- Do not send `.env` in support screenshots. Redact keys.
